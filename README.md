# CHT-Test

Personal single-page website for Pheelip Sim — AI Educator & Enterprise AI Practitioner.

## Stack

Next.js 15 (App Router) + TypeScript + Tailwind CSS v4 + shadcn/ui (Base UI). Light/dark theme via next-themes, Geist font, Lucide icons.

## Run locally

```sh
npm install
npm run dev
# open http://localhost:3000
```

Production build: `npm run build` then `npm start`.

## Deploy (Vercel)

Import this repo in Vercel — the Next.js framework preset is detected automatically. Pushes to `main` deploy to production.
